A personal, unlimited visual workspace and infinite note-taking board inspired by Milanote. Built to organize ideas spatially without storage limits.


link : http://localhost:5173/


- **Frontend:** React, React Flow (`@xyflow/react`), Vite
- **Backend (In Progress):** Python, Flask, SQLite


 Features
- Infinite pan-and-zoom dot-grid canvas
- Draggable, editable floating note cards
- Local SQLite persistence
